# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**, or go straight to [the private reporting form](https://github.com/DonQuinleone/octodns-views/security/advisories/new).

Please do not open a public issue, pull request or discussion for a vulnerability.

A useful report includes:

- the version of octodns-views, and whether you installed it from PyPI or from source
- what an attacker can do, and what they need first
- steps or a configuration that reproduce it, with any credentials removed

## Supported versions

| Version | Supported |
|---|:---:|
| Latest stable release | ✅ |
| Latest pre-release, until its stable release ships | ✅ |
| Anything older | ❌ |

## Scope

In scope: the code in this repository and the `octodns-views` package it publishes on PyPI.

Out of scope, and best reported elsewhere:

- vulnerabilities in octoDNS itself: follow the [octoDNS security policy](https://github.com/octodns/octodns/security)
